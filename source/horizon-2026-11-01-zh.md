### [Parameter Labs 披露可接管 ChatGPT 账户的漏洞链](https://simonwillison.net/2026/Oct/31/how-we-took-over-chatgpt-accounts/) ⭐️ 8.0/10

Parameter Labs 公开了一条针对 ChatGPT HTML 预览（原 Canvas）沙箱 iframe 的漏洞利用链：攻击者可在共享链接中植入恶意 HTML，当已登录用户打开该链接时，代码能突破沙箱并读取其私有数据或代其执行操作。攻击链利用 OpenAI 图表功能所用 MathLive 库的虚拟键盘——父页面通过 postMessage\(\) 接收消息并用 innerHTML 插入内容，且未限制来源；随后注入无沙箱限制的新 iframe，再借 CSP 白名单中的 YouTube oEmbed 端点反射执行 JavaScript。OpenAI 已修复该漏洞并支付 5,000 美元赏金，Simon Willison 认为这一金额偏低。

rss · Simon Willison · 10月31日 23:15

**「背景」** ChatGPT 的 HTML 预览（此前称为 Canvas）把交互式自定义 HTML 应用放在沙箱 iframe 中运行，目的是阻止不受信任的代码接触 OpenAI API 和用户私有数据。Parameter Labs 的披露显示，这一隔离被主页面加载的第三方数学输入库 MathLive 打破：其跨帧消息监听器不校验消息来源，可被沙箱 iframe 通过 postMessage\(\) 调用。

**「影响与建议」** 该漏洞的关键风险在于攻击面来自共享链接而非用户主动运行代码：任何已登录用户点击他人分享的 ChatGPT 链接都可能中招。修复已由 OpenAI 完成，用户无需额外操作，但此案例说明沙箱 iframe 的 postMessage 接收端必须校验消息来源，CSP 白名单域名也应视为潜在脚本执行通道。
